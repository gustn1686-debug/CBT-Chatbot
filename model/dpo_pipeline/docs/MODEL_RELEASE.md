# 학습 모델과 서비스 주소 기록

현재 배포 주소·DPO 어댑터·최종 평가 결과는 없다. [model_release.json](../model_release.json)의 `null`은 미정이며 실제 주소가 아니다.

최종 CTRS 평가와 후속 검토 후 다음 항목을 채운다.

1. 베이스 모델 ID와 고정 revision, 토크나이저 revision.
2. DPO 어댑터 또는 가중치의 접근 주소·고정 revision·체크섬, 학습 설정과 데이터 manifest 식별자.
3. 최종 60프로필 평가 결과 문서 주소와 실제 비교한 체크포인트.
4. 서비스 추론 endpoint와 `served_model_name`, 상담 프롬프트 해시와 추론 양자화 조건.
5. 검토·배포 상태와 필요한 접근 권한. 접근 토큰은 서버 secret으로 관리하고 주소 파일에 넣지 않는다.

어댑터는 정확한 베이스 가중치와 조합해야 한다. 어댑터 주소·병합 가중치 주소·서비스 추론 주소는 서로 다르다. 서비스 backend는 등록한 endpoint에서 평가를 마친 동일 체크포인트를 사용하도록 연결한다.

CTRS 평가용 Sol과 대안 생성용 Sol은 연구 도구다. 사용자에게 상담하는 배포 모델은 DPO Qwen3.5-27B다. 이 PR은 서비스 서버·backend 연결·모델 업로드·자동 배포를 실행하지 않는다. 기존 서비스 코드를 유지하고 `model/README.md`에 연구 및 모델 주소의 입구를 추가한다.
