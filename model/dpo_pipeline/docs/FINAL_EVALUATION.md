# 최종 비교 설계 · 아직 미실행

목표는 **편집한 대화의 점수가 아니라, 학습된 모델 자체의 상담 성능**을 비교하는 것이다.

| 자료 | 용도 |
| --- | --- |
| 기존 60 + 논의 중인 추가 60프로필 | 선호쌍 생성과 훈련 후보. 추가 60은 미생성 |
| 별도 개발·검증 그룹 | 학습 설정과 체크포인트 선택. 구체적인 선정은 미확정 |
| 독립된 최종 60프로필 | 베이스 60회기 + DPO 60회기, 총 120회기. 아직 미실행 |

## 자료 분리

프로필과 원천 내담자 그룹 단위로 나눈다. 같은 회기의 턴을 훈련과 평가에 나눠 넣지 않는다. 같은 사례의 변형과 의미상 중복도 점검한다. 최종 60프로필의 결과로 학습 설정·평가 프롬프트·선호쌍을 수정하거나 체크포인트를 고르지 않는다.

## 새 상담 생성

두 모델은 같은 프로필·시작 발화·상담 프롬프트·최대 턴 수·추론 조건·내담자 시뮬레이터 조건으로 처음부터 상담한다. 내담자는 각 모델의 응답에 맞춰 새로 응답한다. 베이스의 후속 반응을 DPO 상담에 그대로 복사하지 않는다.

모델·토크나이저 revision, 양자화, 어댑터, 무작위성 설정과 생성 코드 해시를 기록한다. 두 조건에서 동일하게 맞출 설정과 허용할 차이를 실행 전에 고정한다.

## 동일 CTRS 평가와 보고

평가자에게 실제 사전 자료를 제공하고 같은 6척도·언어·턴 지침을 사용한다. 조건명은 중립화한다. 미래 대화는 회기 전체 평가에는 사용할 수 있지만, 개별 턴의 피드백과 학습 힌트에는 들어가지 않게 한다. 점수를 높이기 위한 재채점을 하지 않는다.

보고할 값은 완료율, 모델별 평균, 같은 프로필별 점수 차이의 평균·분포·불확실성, 상승·동일·하락 수, 6항목별 변화, 언어 혼입과 잔여 문제다. 미완료를 0점이나 동률로 집계하지 않는다. 한 모델만 완료한 프로필은 실패율과 함께 보고하고, 완료된 비교 쌍의 분모를 표시한다.

반복 생성·반복 채점의 범위와 불확실성 계산법은 실행 전에 정한다. 자동 개선의 최소 폭과 상담사 검토로 넘어갈 수치 기준은 아직 미확정이다. 같은 Sol 계열이 생성과 평가를 맡은 문체 선호 가능성도 한계로 보고한다.

자동평가에서 개선을 확인한 뒤 상담사 검토를 요청하는 사용자 순서를 유지한다. 학습 전 전문가 전수 검토를 새 필수 조건으로 두지 않는다. 최종 결과와 실제 평가한 체크포인트를 `model_release.json`에 연결하며, 지금의 편집본 4.17점을 DPO 모델 성능으로 표시하지 않는다.
