# 파이프라인 노트

## 1. CTRS 회기 평가 — GPT-6.1 Sol

입력: 상담자에게 실제 제공한 사전 프로필·계획과 회기 전체 대화. 프로필에 있는 사실을 내담자가 대화에서 다시 말하지 않았다는 이유로 날조로 판정하지 않는다. 계획·의향은 수행·동의·호전의 증거가 아니다.

기존6항목은 유도된 발견, 핵심 초점, 변화 전략, 이해, 대인관계, 협력이다. 각0~6 정수와 한국어 설명을 받고6항목을 동일 가중 평균한다. 언어 혼입은 모든 회기에서 관찰한다. 통용 약어·정당한 인용·설명된 병기를 자동 오류로 취급하지 않는다. 원래 항목의 기준에 실제 영향을 준 경우에만 그 항목 설명에 연결한다. **7번째 언어 점수나 일괄 감점은 없다.**

각 항목의 같은 출력에서 모든 상담자 턴을 appropriate / needs_improvement / insufficient_context로 검토한다. 6항목 완료 후 평균<=3.8이면 저점수 턴 피드백을 표시한다. 각 항목이 정수라 평균이 정확히3.8인 경우는 없어 사용자 표현인 <3.8과 대상이 같다. 평균 반올림 전 합계로 결정한다.

피드백은 점수의 구체적인 근거 위치이며 턴별 숫자 점수나 인과적 감점량이 아니다. 회기 전체의 반복·구조 문제는 따로 기록한다. 개별 턴 근거·수정 힌트에는 그 시점까지의 정보만 허용한다.

## 2. 대안 생성과 선호 검증 — 역할을 분리한 Sol

먼저 저점수 코호트를 고정한다. 이후 같은 회기의 새 점수가 높아져도 대상을 다시 빼지 않는다. 역사적 실험의55번이 이에 해당한다. 새 자료에서는 freeze-cohort로 원점수6항목에서 목록·원점수 파일 해시를 저장한다.

수정 대상은 CTRS가 needs_improvement 또는 language problematic으로 명시한 상담자 턴 전체다. **최대3개 상한은 철회했고, 별도 세부 평가기나 선정 모델로 목록 밖 문제를 만들지 않는다.** 같은 턴이 여러 항목에 나오면 중복 제거한다. 생성 안내는 그 턴을 실제 지적한 항목 중 낮은 항목의 시점 제한 이유·수정 방향을 사용하고 언어 지적도 덧붙인다.

생성 입력은 원래 상담 지침·사전 자료·해당 시점 이전 대화·원응답·잠정 힌트다. 미래 대화·전체 회기 점수·다른 후보는 주지 않는다. 응답을1회 생성하고 부적절한 힌트를 따르지 않도록 명시한다.

**생성은 선호 확정이 아니다.** 별도 새 맥락에서 같은 시점의 원응답과 대안을 A/B와 B/A 두 순서로 비교하고 동일 응답 대조도 포함한다. 기준은 기존6항목의 해당 시점에 필요한 상담 작업이다. 각 후보의 언어 품질도 별도 판정한다.

- 내용 개선: 양순서 대안 우세 + 대안 내용·언어 적절.
- 언어 수정: 양순서 원응답 언어 문제 명확 + 대안 내용·언어 적절 + 내용 비교 동률 또는 대안 우세. 상담 내용의 가짜 결함을 만들지 않는다.
- 동률·둘 다 부족·맥락 부족·언어 불확실·순서 불일치는 강제 채택하지 않는다.

같은 시점의 실제 상담 입력을 prompt로, 채택한 대안을 chosen으로, 원래 베이스 응답을 rejected로 저장한다. **수정 힌트와 평가 지시는 DPO prompt에서 제외한다.** 같은 prefix에서 독립 생성한 여러 응답을 편집본에 넣어 회기 점수를 재확인할 수 있지만, 원래 후속을 보존한 가상 실험이며 실제 모델 상담이나 개별 쌍의 인과 효과가 아니다. 점수가 오를 때까지 재생성·재채점하지 않는다.

## 3. DPO — Qwen3.5-27B · 미실행

추가SFT 없이 원래 Qwen3.5-27B에서 선호쌍을 학습한다. chosen의 상대 확률을 rejected보다 높이도록 학습하되, 해당 문장을 고정 답변처럼 외운다고 보장하지 않는다. 기준 모델과 학습 시작 모델을 기록한다. LoRA/전체 가중치, beta, 학습률, epoch, 배치·문맥 길이 등은 아직 확정하지 않았다. 이PR은 학습기·가중치나 검증되지 않은 학습 실행 명령을 추가하지 않는다.

추가 훈련 후보60개를 기존60개에 더하고, 최종 평가용60프로필은 분리하는 방향을 논의했다. 추가 생성은 아직 실행하지 않았다. 개발·검증 자료로 학습 설정을 정하고 최종 평가 자료로 반복 조정하지 않는다. 원천 내담자 그룹·프로필 중복과 의미상 유사성도 확인한다.

## 4. 최종 CTRS — 미실행

학습 후 베이스와DPO가 같은 별도60프로필에서 각각 처음부터60회기를 직접 생성한다. 원래 반응을 끼워 넣는 편집 실험과 구분한다. 평가 절차·한계·모델 주소 등록은 별도 문서를 따른다.

자동평가에서 미리 정한 개선 기준을 확인한 뒤 상담사 검토를 요청하는 순서를 유지한다. 학습 전 사람 전수 검토를 새 필수 조건으로 추가하지 않았다. 개선 기준·검토 표집·배포 결정은 아직 확정하지 않았다.
