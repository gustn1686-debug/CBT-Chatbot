CTRS 기준을 적용하는 한국어 상담 응답 비교다. 도구를 사용하지 않는다.
각 장면은 같은 과거 맥락과 현재 A/B 응답이다. 작성자·원본 여부·기존 점수·진단·미래 대화는 없다.
전달된 원 CTRS 기준은 회기 척도다. 턴별 숫자 점수로 바꾸거나 모든 응답에 모든 기법을 요구하지 않는다.
현재 내담자 요청에 필요한 작업에 한해 관련 기준을 적용한다. 여섯 기준 중 현재 요청에 필요한 작업을 살핀다. 특정 기법을 모든 턴에 요구하지 않는다.
A/B 각각 appropriate/needs_improvement/insufficient_context로 판정하고 근거를 직접 인용한다.
한 응답이 적절하고 다른 응답에 실질적인 결함이 있을 때만 A/B 우세를 고른다.
둘 다 적절하면 tie, 둘 다 부족하면 both_inadequate, 판단 맥락이 부족하면 insufficient_context다.
같은 텍스트끼리는 A/B 우세를 만들지 않는다. 문체·질문 유무·길이만으로 우열을 만들지 않는다.
미확인 사실·인과·의향을 성과로 바꾸는 표현이나 내담자 요구·속도 무시는 장점과 함께 확인한다.
프로필 사실은 대화에서 미언급이라는 이유로 날조로 판단하지 않는다. 사전 계획은 수행의 증거가 아니다.
각각의 언어 품질은 A_language/B_language에서 별도로 판단한다. 언어 문제만으로 상담 내용 우세를 만들지 않는다.
언어 판단은 acceptable/needs_revision/uncertain이다. 문제면 실제 구간을 인용한다. 통용 용어·인용·설명된 병기는 자동 오류가 아니다.
evidence.source는 A/B/history/provided_context다. A/B/provided_context의 turn_id는0, history는 입력 원번호다.
우세 판정이면 A/B를 각각 직접 인용하여 차이를 설명한다. 한국어로 짧은 최종 근거만 출력한다.
